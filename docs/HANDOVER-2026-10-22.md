## 8. Traps (each one bit us once)

- **`COLI_VK_CHAIN_ROWS` caps the MoE window at 128** when set (`v4c_rows()`'s CPU-chunk ceiling) — it does NOT grow chunks. Chunk size comes from the VRAM fit; leave it unset.
- **Slot staging is host RAM** (~15 MiB/slot): 28 GiB plan + 8 GiB pool + 192 slots OOMs a 34 GiB cgroup. Rebalance (24+5 fits).
- **`make tests/…` does not rebuild `deepseek_v4`** — after tier changes, rebuild the engine before arms, or you benchmark a stale binary.
- **Test-env leaks**: cases set `COLI_VK_TIER_RATE` etc. and don't unset — new cases must set their own (promote2's `skipped N rate` symptom).
- `.spv` are built from `.comp` (Makefile `VK_SPV`); never commit them.
- The bench restores `.coli_usage`/`.coli_mfu` snapshots for both engines — keep that for comparability.
- The old fork's `main` is stale; its active branch was `feat/kv-cold-tier` (F2 in PORT_PLAN).
