the charter's gates admit ~nothing. The port's *inline* prefetch survives because chunk 0's steps plan
by **heat** (the frozen usage snapshot), which at S=2048 clears the R bar for nearly every cold expert
(~146–219 a step — the 12 558). The ring's decode-side joins are clean (RING decode 0.5687 vs C0's
0.5751, −1.1 %; share, ops, loads all ≡ C0).

## 7. RINGCOLD — skipped, the gap recorded verbatim

The arm needed "the fork-literal cold shape (the whole-layer first-chunk fill)". AN §5's own
registration: *"the fork's literal cold shape — a whole-layer fill with no prediction — which is a
one-rule arm on this machinery (`st_ring_submit`'s cold branch filling the plan's whole non-resident
set instead of nothing)"* — a **code change**, not an env: at the tip, `st_ring_submit`'s cold branch is
`if (next >= T.main_layers || !T.pred || !T.pred_ok[next]) return 0;` (vk_tier.c) and no environment
variable arms it (verified: the tree's only ring env is `COLI_VK_TIER_STREAM_RING`, the on/off switch).
Per the lane's instruction the gap is recorded verbatim and the arm skipped — no code improvised. The
§4 finding sharpens what that one rule must become: the cold branch is *also* where the fork's
unconditional coverage lives for the predicted branch — the follow-up wants the plan's coverage
question (heat-or-whole-layer, in-RAM exclusion) answered beside the cold rule, or the same empty-plan
class will meet it.
